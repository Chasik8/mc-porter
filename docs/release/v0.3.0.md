# porter 0.3.0

## Highlights

- **Testkit client mode**: scenarios can open a GUI on a real client and press its controls like a player
  (`gui_input: {press: {id|index|label|kind}}`), so the real client packet is sent. Every GUI capture records the
  screen's buttons in the trace. The driver never touches the user's mouse or window focus.
- **Networking bridge**: 1.19.2 `SimpleChannel` code (`registerMessage`, `send`, `sendToServer`, `reply`,
  `PacketDistributor`, `NetworkEvent.Context`) ports without edits. One 1.7.10 `SimpleNetworkWrapper` is created per
  channel and every message travels in one generic message (id + bytes). 32 rules and shim classes in the adapter pack.
- **Upfront layer and `porter precheck`**: the translation of a mod's platform symbols is prepared as data before the
  first compile (`porter upfront`: inventory, version lineage, scored matcher, emitted rules, shim skeletons, a
  bodies database filled once and compile-checked in one javac). `porter precheck` checks a change to a rule, overlay
  or edit in about a minute instead of a full run.
- **Scenario and content generators**: `testkit/scengen` writes "machine processes recipe", storage, charging and
  generator scenarios from recipe and menu IR; `ports/ic2c-steam/cropgen` emits crop classes from a data file.
  `scripts/ci/gen-machine-scenarios.py` and `gen-block-smoke.py` write machine and per-block smoke scenarios.
- **Recipes and ids**: `--id-map` accepts a `tags:` section for ingredient tags, and a testkit probe counts the
  crafting recipes of a registry name whose ingredients all resolve.
- **Port report**: the install stage lists every call in kept code that targets an inert hub-stub member, so a silently
  missing feature (sounds, item icons) shows up at build time. `assets --literals` keeps texture and sound path
  literals of the listed sources.
- **Adapter pack**: generic Minecraft/Forge 1.19.2 -> 1.7.10 mappings that ports had written by hand are now public
  rules with their helper classes (`generic-*.rule.yaml`); `ResourceKey` instances are interned like in 1.19.2;
  `MetaBlock` for block constants that are one metadata subtype of a shared 1.7.10 block.
- **Rule language**: patterns match and rewrite cast expressions and type metavariables; rule conflicts of the same
  priority are rejected by a check in `scripts/check.sh`.
- **Compile stage**: more decompiler-artefact fixes (lost local declarations, leftover generic names, raw casts), run
  until the error list stops changing.
- **Docs**: a plain-English README with a player quickstart, `docs/ARCHITECTURE.md`, a guide on using an AI coding
  assistant for the symbol-resolution step (with measured cost), and the BuildCraft 7.1.23 kinesis fix.
