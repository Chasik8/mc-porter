# Modern Forge API adapters (1.19.2 -> 1.7.10)

Java 8 sources in `dev.porter.shim.mc` that give rewritten 1.19.2 code the 1.19.2 API shape on Forge 1.7.10
(10.13.4.1614). The rules of this pack map 1.19.2 symbols onto them; the port
copies them into the mod and relocates `dev.porter.shim` into the mod's own package (`--shim-package`), so two
ported mods never share classes.

Sources: `rewrite/shim/src/adapters/java/dev/porter/shim/mc` (part of the bundled adapter pack, next to
BlockState/StateBlock, ModernTileEntity, LazyOptional, Capability, ...). Rules: `modern-api-*.rule.yaml` in this
directory, generated by `modern_api_spec.py`. Written for the TorchMaster demo port (ports/torchmaster).

| file | 1.19.2 API |
|---|---|
| `ModLifecycle`, `FMLJavaModLoadingContext`, `ModLoadingContext`, `IEventBus`, `ModEvents`, `Mod` | mod constructor, mod event bus, lifecycle events, `@Mod.EventBusSubscriber` (static subscribers), server events |
| `ForgeConfigSpec`, `ModConfig` | `ForgeConfigSpec` builder/values backed by a 1.7.10 `Configuration` file |
| `DeferredRegister`, `RegistryObject` | deferred registration of blocks, items, block entity types |
| `LevelCaps`, `CapabilityManager`, `CapabilityToken`, `AttachCapabilitiesEvent`, `INBTSerializable`, `ICapabilitySerializable` | capabilities attached to a Level, persisted in per-world saved data |
| `EntityType`, `MobCategory` | entity type keys (1.19.2 ids for vanilla mobs), categories, `ForgeRegistries.ENTITY_TYPES` |
| `cmd/*` | literal-only brigadier commands as 1.7.10 `CommandBase` |
| `PropItem`, `PropBlockItem`, `ItemProperties`, `CreativeModeTab`, `InteractionResultHolder` | `Item.Properties`-based items, block items, creative tabs |
| `AirBlock`, `DirectionalBlock`, `EntityBlock`, `VoxelShape`, `CollisionContext` | block bases, shapes |
| `SpawnEvents`, `VillageSiegeEvent` | 1.19.2 spawn-event accessors; the siege event (never posted on 1.7.10) |
